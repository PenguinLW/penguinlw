# penguinlw

Discord-клиент проекта PenguinL. Бот реализован в `penguinl_d.py` и содержит
обработчики подключения, команд и входящих сообщений.

## Состав

- `penguinl_d.py` — точка входа Discord-бота;
- `.env.example` — пример локальной конфигурации;
- `requirements.txt` — зависимости;
- `app_run.sh` — локальный запуск;
- `release.sh` — публикация изменений в одноимённый Git-репозиторий.

Файл `.env` содержит локальные параметры и не должен попадать в Git.
